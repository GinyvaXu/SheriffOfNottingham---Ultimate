# v1.7.0 - Screen animations, roomier windows, match history

**English / 中文**

## English
- **New: screen transition animations.** Every screen switch now fades in smoothly (no more instant jumps).
- **New: the 6-player table is no longer cramped.** Player panels compact automatically for 5-6 players, and the whole UI renders on a fixed 1280x800 logical canvas that is scaled onto your real window - the bigger the window, the more room the table has.
- **New: Settings screen.** Pick a window preset (1280x800 / 1600x900 / 1920x1080 / 2560x1440), enter a custom width/height, or toggle **fullscreen** and **borderless** modes. Great for easing GUI crowding.
- **New: Match History screen.** Every finished game automatically records the date/time, player count, round count, detailed final scores (goods value + gold + end bonus) and the final ranking; the list keeps the latest 50 games and can be cleared with one click. Data is stored locally in %APPDATA%/SheriffOfNottingham/history.json.
- **New: Sponsor button** on the main menu - opens the developer's Love Power (爱发电) page in your browser.
- **Polish: Black Market quest panel redesigned** - colored goods chips, a gold-rimmed quest board, star-marked 1st/2nd reward slots, and a hint showing how many cards each quest needs.
- **Change:** all bundled mod versions are synced with the game build (1.7.0).

## 中文
- **新增：切屏过渡动画。** 切换界面时平滑淡入，不再生硬跳转。
- **新增：六人局不再拥挤。** 5-6 人时玩家面板自动紧凑化；整个界面以固定 1280x800 逻辑画布渲染并等比缩放到真实窗口，窗口越大桌面越宽敞。
- **新增：设置页。** 可一键切换窗口预设（1280x800 / 1600x900 / 1920x1080 / 2560x1440）、自定义宽高，或开启**全屏**、**无边框**模式，缓解 GUI 拥挤。
- **新增：历史战绩页。** 每局结束自动记录日期时间、人数、回合数、详细分数（货物价值+金币+终局加成）与最终排名；保留最近 50 局，可一键清空。数据保存在 %APPDATA%/SheriffOfNottingham/history.json。
- **新增：首页"赞助"按钮。** 点击后在浏览器中打开作者的爱发电主页。
- **美化：黑市任务面板重做。** 彩色货物芯片、金色描边任务板、首/次席奖励槽位星标，并提示每个任务所需凑齐的数量。
- **同步：** 所有内置模组版本与游戏版本同步为 1.7.0。
